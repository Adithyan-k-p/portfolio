# 🌐 Adithyan K P — Developer Portfolio

A terminal-inspired, cyber-themed interactive portfolio website built with HTML5, Vanilla JavaScript, and Tailwind CSS. Hosted on GitHub Pages.

🔗 **Live Demo**: [Adithyan-k-p.github.io/Portfolio](https://adithyan-k-p.github.io/Portfolio/) *(or your deployed GitHub Pages URL)*

---

## ⚡ Highlights

- **Interactive CLI Shell**: Emulated terminal with built-in commands (`help`, `projects`, `stack`, `whoami`).
- **Generative Canvas & Audio**: Real-time visualizers & synthesized Web Audio API feedback.
- **Responsive Cyber UI**: Dark aesthetic with CRT overlay toggle, smooth navigation, and modal views.

## 🛠️ Tech Stack

- **Frontend**: HTML5, Vanilla JavaScript (ES6+), CSS3, Tailwind CSS
- **Design Tokens**: Custom CSS (`style.css`), Google Fonts (*Syne*, *Space Grotesk*, *JetBrains Mono*)
- **Libraries**: `canvas-confetti`, Web Audio API

## 🚀 Quick Run

Open `index.html` directly in any web browser, or serve locally using:

```bash
# Using Python
python3 -m http.server 8000
```
